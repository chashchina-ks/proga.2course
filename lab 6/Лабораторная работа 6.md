### Задача 

Разработать функцию `get_currencies`, которая получает курсы валют с API Центробанка России и возвращает их в виде словаря. Реализовать три итерации с различными подходами к обработке ошибок и логированию

### Пояснение к решению
- currencies.py

1. Функция get_currencies(currency_codes, url="https://www.cbr-xml-daily.ru/daily_json.js")

Принимает список кодов валют (`currency_codes`) и URL API (`url`) в качестве аргументов. Функция обращается к API ЦБ РФ и возвращает словарь, где ключ — код валюты, значение — её курс

2. Логирование ошибок через декоратор

    Декоратор перехватывает три типа исключений:

      - `RequestException` — ошибки API (недоступен, неверный URL). Логирует и поднимает исключение
  
      - `KeyError` — отсутствие ключа "Valute". Логирует и возвращает None
  
      - `Exception` — все остальные ошибки. Логирует и поднимает исключение
      

3. Универсальная функция логирования _log_error

    Определяет тип `handle`:
  
    - Если у объекта есть метод error — это логгер (`logging.Logger`)
  
    - Если есть метод `write` — это поток (`sys.stdout`, `StringIO`)
  
    - Иначе — использует `print()`

4. Итерации реализации

    ***Итерация 1 (базовая) — `get_currencies_iter1`:***

    - Обработка ошибок через `try-except`

    - Вывод ошибок в переданный `handle`

    - При ошибке API поднимается исключение

    ***Итерация 2 (декоратор) — `get_currencies_iter2`:***

    - Логирование вынесено в декоратор `@trace()`

    - Основная функция содержит только бизнес-логику

    - Декоратор автоматически обрабатывает ошибки

    ***Итерация 3 (logging) — `get_currencies:`***

    - Использует модуль `logging`

    - Настройка логирования через `logging.basicConfig()`

    - Логирование с уровнями: `error`, `warning`, `info`
